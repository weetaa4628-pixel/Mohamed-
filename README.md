Student Task Manager
Description
Student Task Manager is a simple Python application that helps students manage their academic tasks.
The application allows users to add new tasks, view their current tasks, and delete completed or unwanted tasks.
Installation
Install Python on your computer.
Download or clone this project from GitHub.
Open the project folder.
Run the following command:
python main.py
Usage
After running the program, the following menu will appear:
--- Student Task Manager ---
1. Add Task
2. View Tasks
3. Delete Task
4. Exit
For example, select option 1 to add a new task:
Enter a task: Study Computer Networks
Task added successfully!
Select option 2 to view your tasks.
Select option 3 to delete a task.
Select option 4 to exit the program.
